# Contributing to HumanAI Evolution Trilogy Research

This repository documents and extends the HumanAI Evolution Trilogy. All contributions should maintain publication integrity, clear provenance, and accurate attribution.

## For the Published Trilogy

The Trilogy comprises three published research works. Do not modify published work metadata without verification against authoritative sources (Zenodo records).

To discuss trilogy-related research or extensions:
1. Open an issue with the `trilogy` label
2. Reference the relevant layer (Genesis/Paper 1, Dharma/Paper 2, or Karma/Paper 3)
3. Clearly distinguish between published work and your extension/analysis

## For New Research

If adding new research related to the trilogy:

1. **Obtain publication metadata:**
   - DOI or persistent identifier (required)
   - Full title and authors
   - Publication date and venue
   - Resource type (paper, dataset, software, etc.)
   - License information

2. **Add to TRILOGY_PUBLICATIONS.md:**
   - Use the template provided
   - Mark any unverified fields as "To be verified"
   - Include full citation in BibTeX format
   - Link to related repositories or resources

3. **Do NOT:**
   - Claim unpublished work as published without authoritative evidence
   - Modify verified publication metadata without source verification
   - Leave publication status ambiguous

## For Experimental/In-Progress Work

If developing research inspired by or extending the trilogy:

1. **Clearly label your work:**
   - Use branch names, directory names, or README sections to indicate status
   - Mark as "experimental," "in-progress," "draft," or "preliminary" as appropriate
   - Never imply that unpublished work is part of the published trilogy

2. **Include a README or documentation** explaining:
   - Research question and methodology
   - Status (in progress, preliminary results, etc.)
   - Relationship to trilogy layer(s)
   - Expected timeline or next steps

3. **Do NOT:**
   - Merge experimental work to main branch without clear completion markers
   - Use publication language for unpublished work
   - Claim connection to published trilogy work without explicit distinction

## Publication Standards

All contributions must follow these standards:

- **Accuracy:** Metadata must be verifiable against authoritative sources (Zenodo, journals, etc.)
- **Transparency:** Clearly distinguish between published, in-progress, preliminary, and proposed work
- **Attribution:** Clearly credit authors, contributors, and funding sources
- **Provenance:** Document version history and publication records
- **Licensing:** Respect CC BY 4.0 (trilogy publications) and other applicable licenses

## Questions?

Open an issue in this repository with details about your contribution or questions about the trilogy.
